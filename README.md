# OIDC Login for Jellyfin

A Jellyfin 12.x plugin that lets people sign in to the Jellyfin web UI through one OpenID Connect Identity Provider. It is tested against PocketID, so passkeys become the way into Jellyfin. Local Login keeps working.

## Installing

The Plugin is published in its own plugin repository, so Jellyfin installs and updates it like any other plugin.

1. In Jellyfin, open **Dashboard → Plugins**, go to **Repositories**, and add a repository:
   - **Name:** `OIDC Login`
   - **URL:** `https://nicoflink.github.io/jellyfin-oidc-plugin/manifest.json`
2. Open **Catalog**, find **OIDC Login** under *Authentication*, and install it.
3. Restart Jellyfin.

Each release is built for one Jellyfin minor version and needs at least that version. Jellyfin only offers releases whose target version your server meets, so update Jellyfin first if the latest release doesn't show up.

## Releases

Releases come only from the [Release workflow](.github/workflows/release.yml). The version is the git tag `vMAJOR.MINOR.PATCH`; nothing commits to `main`.

- **Automatic:** a push to `main` that changes `targetAbi` in `build.yaml` (a Jellyfin bump) releases the next patch, with the notes "Built and tested against Jellyfin 12.N".
- **Manual:** run the workflow from the Actions tab and choose `major`, `minor` or `patch`. The notes are generated by GitHub.

Each release attaches the jprm-built zip and its `.md5` to the GitHub Release and adds the version to `manifest.json` on the `gh-pages` branch.
